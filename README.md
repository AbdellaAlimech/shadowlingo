# ShadowLingo

Application gratuite de shadowing pour francophones : chinois mandarin et anglais.

**Ouvrir l'application : https://abdellaalimech.github.io/shadowlingo/**

Fonctionne dans le navigateur, s'installe sur smartphone (Ajouter à l'écran d'accueil) et marche hors ligne.
Voix synthétiques intégrées (Kokoro-82M, Apache 2.0). Aucun compte, aucune publicité.
